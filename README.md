### Smart Leak Detection System

A reconstruction and improvement of my high-school engineering capstone project.

The original system used an ESP32, a pressure sensor, Bluetooth communication, and a custom MIT App Inventor mobile application to monitor water pressure and warn the user when readings moved outside a defined range.

The rebuilt version will focus on:

- Correct sensor voltage and signal conditioning
- Improved calibration and testing
- Reliable Bluetooth communication
- A redesigned mobile interface
- Data logging and leak-detection logic
- Clear engineering documentation

**Technologies:** ESP32, pressure sensing, Bluetooth, embedded C/C++, mobile application development

[View the Smart Leak Detection System repository](https://github.com/hafnervaughn-projects/smart-leak-detection-system)
